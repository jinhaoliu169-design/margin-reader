# 页边 MARGIN

面向英语小说精读的本地 Web 应用。包含 620 本可直接免费阅读全文的公版英语小说、选中标记、有道词典释义、截图 OCR、文章导入、生词本和学习数据导出。

## 启动

1. 确认电脑已安装 Python 3.10 或更高版本。
2. 双击 `启动网站.cmd`。
3. 浏览器会自动打开 `http://127.0.0.1:8765/`。

也可以在终端中运行：

```powershell
python server.py
```

长期公网部署请见 [DEPLOY.md](DEPLOY.md)。项目已包含 `Dockerfile` 和 Render Blueprint，支持访问密码、持久磁盘和按浏览器隔离的“我的文章”数据。

## 主要功能

- **书库**：620 本书目，覆盖经典文学、奇幻、科幻、悬疑、爱情、历史、成长、惊悚与当代畅销书；每本都显示英文原名和中文译名，支持按中英文书名、作者、类型、年代和全文可用性筛选。
- **直接阅读**：主书库全部是可免费阅读全文的公版小说，点击书卡直接进入正文。
- **全文阅读**：620 本小说全文来自 Project Gutenberg，首次打开会缓存到本机。
- **标记查词**：在正文中选中单词或短语，点浮动工具栏里的“标记”。颜色会保留在原文，右侧词典面板同步显示音标、英式/美式发音、简明释义、考试标签、词形变化、英文释义、例句、短语和词源。
- **取消标注**：浮动标记条可直接取消本次操作；已保存的标注可点击原文高亮，在词典底部点“取消这个原文标记”，或在“生词本 → 原文标记”中删除。
- **逐段翻译**：内置小说与导入文章都支持按段显示中文译文，默认全部收起；每段可单独展开/收回，顶部可一键展开或收起本页译文。导入文章会在后台预生成整篇译文。
- **截图 OCR**：把 PNG、JPG、WebP 或 GIF 拖到页面任意位置，或进入“截图精读”选择图片。英文在浏览器内识别，结果可编辑后进入同一套阅读与标记流程。
- **文字导入**：支持拖入 TXT / Markdown，或在“截图精读”中直接粘贴英文段落；可填写英文标题、中文备注和文章来源。
- **后台保存与追加**：导入文章有明确的“只保存 / 保存并阅读”按钮，标题自行命名；保存后可在阅读页点“继续添加内容”，继续拖入截图或粘贴文字并追加到原文。文章的标题、中文备注、来源与正文保存在本机 `work/store/imports.json`。
- **同来源追加**：截图识别完成后，如果已有相同来源的文章，保存区域会出现文章选择器，可以直接追加到之前那篇文章。
- **我的页面**：集中显示在读书目、已读页数、原文标记、生词、我的文章与阅读记录；文章可编辑备注、继续添加或删除。
- **回收站**：删除文章先进入回收站，可恢复或彻底删除；回收站支持清空。
- **响应式**：桌面端为书页 + 侧栏词典；手机端词典从底部展开，底部导航切换书库、阅读、导入和生词。

## 数据与网络

- 书目与封面：Open Library。
- 公版全文：Project Gutenberg。
- 中文释义、音标、例句、短语与词源：有道词典公开查询响应，通过本地服务代理并缓存 30 天。
- 逐段中文译文：有道翻译接口，通过本地服务批量翻译并按原文缓存。
- OCR：Tesseract.js，首次识别时会从 jsDelivr 加载英文识别模型。
- 字体：Newsreader、Manrope、Source Serif 4，均以 SIL Open Font License 1.1 随项目分发；许可证位于 `app/assets/fonts/`。

有道词典或 OCR CDN 暂时不可达时，页面会显示可恢复的错误状态。内置的少量本地简释可用于演示离线降级，文字粘贴与已经缓存的公版全文不依赖词典服务。

## 隐私

- 图片只在浏览器内识别，不上传到本项目服务器。
- 词典请求只发送当前选中的英文词条。
- 导入文章保存在本机后台目录，不上传云端；阅读标记、生词与进度保存在浏览器本地。清除浏览器站点数据会删除后者，建议定期在生词页导出备份。
