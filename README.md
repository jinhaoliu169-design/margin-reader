# Eleven 精读书库

面向英语精读的 Web 应用。包含 620 本可直接免费阅读全文的公版英语小说、520 篇四级/六级/雅思原创分级外刊精读、选中标记、有道词典释义、截图 OCR、文章导入、百词斩式背单词和学习数据导出。

## 启动

1. 确认电脑已安装 Python 3.10 或更高版本。
2. 双击 `启动网站.cmd`。
3. 浏览器会自动打开 `http://127.0.0.1:8765/`。

也可以在终端中运行：

```powershell
python server.py
```

公网版本：<https://pianbian-margin.netlify.app>。更新与重新部署请见 [NETLIFY.md](NETLIFY.md)。

## 主要功能

- **书库**：620 本书目，覆盖经典文学、奇幻、科幻、悬疑、爱情、历史、成长、惊悚与当代畅销书；每本都显示英文原名和中文译名，支持按中英文书名、作者、类型、年代和全文可用性筛选。
- **外刊精读**：520 篇站内原创分级精读（四级 200 篇、六级 160 篇、雅思 160 篇），每篇约 300–370 词、15 段左右完整文章；标注参考刊物、官网、难度和重点词，可直接在站内阅读、翻译和标记。
- **外刊查找**：输入刊名或文章名，显示所属刊物、官网、通常免费/部分免费/付费状态，以及百度、Bing、Google 和官网搜索入口；可保存为「我的外刊链接」。
- **截图精读外刊**：从「我的外刊链接」点「截图精读」，标题、中文备注、来源和难度会自动带到截图导入页。
- **直接阅读**：主书库全部是可免费阅读全文的公版小说，点击书卡直接进入正文。
- **全文阅读**：620 本小说全文来自 Project Gutenberg，首次打开会缓存到本机。
- **真实阅读进度**：每一段下面都有「读完这段」勾选，进度按已勾选段落占全文的比例计算；不再按停留时间或翻页数跳进度。
- **划词查词与标记**：选中单词或短语后，可点「查词」直接看释义和发音（不留下标记），点喇叭直接播放发音；点「标记」才会把颜色留在原文。词典未收录短语时，面板会显示整词中文翻译，并始终保留取消标记入口。
- **词形与词根**：自动识别 `-ing`、`-ed`、`-s` 等词形，在词条顶部显示原形、后缀和语法标签，例如 `preserve + -ing（现在分词/动名词）`；词源缺失时显示构词分析，并尝试用原形补查词源和释义。
- **段落 / 全文朗读**：每段有「朗读」按钮，工具栏有「朗读全文」；使用浏览器英语语音按完整句子连读，优先选择美式英语声音，支持暂停、继续和停止。
- **划词朗读**：选中任意词或句子后，可点「只读这句」朗读所在完整句子，或点「从这里读」从该句开始一直往后读并自动翻页。
- **取消标注**：浮动标记条可直接取消本次操作；已保存的标注可点击原文高亮，在词典底部点“取消这个原文标记”，或在“生词本 → 原文标记”中删除。
- **无关文字过滤**：阅读页工具栏的滑块可调整版权页、书名重复、页码、转录说明等无关文字的隐藏数量；默认隐藏前置与后置噪声，拖到 0 可全部保留。
- **逐段翻译**：内置小说与导入文章都支持按段显示中文译文，默认全部收起；每段可单独展开/收回，顶部可一键展开或收起本页译文。整页会一次批量翻译，并在后台预取下一页；导入文章会在后台预生成整篇译文。
- **截图 OCR**：把 PNG、JPG、WebP 或 GIF 拖到页面任意位置，或进入“截图精读”选择图片。英文在浏览器内识别，结果可编辑后进入同一套阅读与标记流程。
- **文字导入**：支持拖入 TXT / Markdown，或在“截图精读”中直接粘贴英文段落；可填写英文标题、中文备注和文章来源。
- **手动生词本**：标记只保留颜色，不再自动进入生词本；在右侧词典点「加入生词本」才会保存。
- **背单词模式**：生词本提供百词斩式选择题记忆，可选 10/20/30/50 个词，支持新词、复习和混合模式；答对拉长复习间隔，答错进入错词复习。
- **发音兜底**：有道音频不可用时自动切换备用音频，再使用浏览器英语语音，数字、短语和 `19th century` 这类词也能朗读。
- **后台保存与追加**：导入文章有明确的“只保存 / 保存并阅读”按钮，标题自行命名；保存后可在阅读页点“继续添加内容”，继续拖入截图或粘贴文字并追加到原文。公网版会同步到 Netlify Blobs，本机仍保留副本。
- **同来源追加**：截图识别完成后，如果已有相同来源的文章，保存区域会出现文章选择器，可以直接追加到之前那篇文章。
- **我的页面**：集中显示在读书目、已读页数、原文标记、生词、我的文章与阅读记录；文章可编辑备注、继续添加或删除。
- **阅读记录管理**：每条阅读记录有独立删除按钮，删除后会同时清掉这本书的段落勾选；误删可以从提示条撤销。
- **回收站**：删除文章先进入回收站，可恢复或彻底删除；回收站支持清空。
- **响应式**：桌面端为书页 + 侧栏词典；手机端词典从底部展开，底部导航切换书库、阅读、导入和生词。
- **可调阅读布局**：阅读页左右两条边线可以拖动，实时挤压/放宽左侧封面和右侧词典；拖到边缘或双击边线即可收起，边缘的「封面 / 词典」标签或工具栏按钮可恢复，最后只保留正文。

## 数据与网络

- 书目与封面：Open Library。
- 公版全文：Project Gutenberg。
- 中文释义、音标、例句、短语与词源：有道词典公开查询响应，通过本地服务代理并缓存 30 天。
- 逐段中文译文：Google 翻译公开接口优先、有道翻译备用，通过本地服务整页批量请求并按原文缓存。
- OCR：Tesseract.js，首次识别时会从 jsDelivr 加载英文识别模型。
- 字体：Newsreader、Manrope、Source Serif 4，均以 SIL Open Font License 1.1 随项目分发；许可证位于 `app/assets/fonts/`。

有道词典或 OCR CDN 暂时不可达时，页面会显示可恢复的错误状态。内置的少量本地简释可用于演示离线降级，文字粘贴与已经缓存的公版全文不依赖词典服务。

## 隐私

- 图片只在浏览器内识别，不上传到本项目服务器。
- 词典请求只发送当前选中的英文词条。
- 公网版的导入文章会保存在本机，并同步到站点后台（Netlify Blobs），方便下次继续添加；阅读标记、生词与进度仍只保存在浏览器本地。清除浏览器站点数据会删除后者，建议定期在生词页导出备份。
